# Reporting System

سیستم مدیریت صنف‌ها، اساتید، نصاب و گزارش‌های هفتگی.

- **نسخهٔ اصلی جدید:** [new version](new%20version/README.md)، با Next.js، TypeScript و MongoDB، رابط فارسی/انگلیسی، تقویم شمسی/میلادی، تم روشن/تاریک، حساب‌های مستقل سرنگران‌ها و خروجی اکسل.
- `frontend/` و `backend/`: کدهای نسخهٔ قبلی React/Vite و PHP/MySQL برای مراجعه و نگهداری.

## اجرای نسخهٔ جدید

```powershell
cd "new version"
npm install
# .env.example را به .env کپی و اتصال MongoDB و مشخصات مدیر اولیه را تنظیم کنید.
npm run setup
npm run dev
```

آدرس محلی در قسمت `Local` ترمینال نمایش داده می‌شود؛ معمولاً `http://localhost:3000/fa` است. راهنمای کامل راه‌اندازی، انتقال داده‌ها و آزمون‌ها داخل پوشهٔ نسخهٔ جدید قرار دارد. حساب‌های تازه از صفحهٔ ورود ثبت‌نام می‌کنند و فضای کاری مستقل دارند.

## تنظیمات خصوصی

فایل‌های `.env`، اطلاعات ورود، داده‌های MongoDB، فایل‌های تولیدشده و پوشه‌های وابستگی در این ریپو قرار نمی‌گیرند. تنظیمات اتصال را برای محیط اجرای خودتان وارد کنید.

برای اجرای احراز هویت بک‌اند قدیمی PHP، فایل `backend/config.example.php` را به `backend/config.local.php` کپی و نام کاربری و هش رمز خود را تنظیم کنید. متغیرهای محیطی `ADMIN_USERNAME` و `ADMIN_PASSWORD_HASH` نیز پشتیبانی می‌شوند. فایل تنظیمات محلی وارد Git نمی‌شود.
